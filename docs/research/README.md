# ExecLocus research

This directory contains an auditable exploratory snapshot used to shape the product and release strategy. It is not a systematic market study or a reproducible competitor census.

- [30-project OSS benchmark](OSS_BENCHMARK_30.md)
- [Launch and communication playbook](LAUNCH_PLAYBOOK.md)
- [Alternatives and current workarounds](ALTERNATIVES.md)
- [Demand-validation plan](DEMAND_VALIDATION.md)
- [ExecLocus adoption blueprint](../ADOPTION_BLUEPRINT.md)
- [Raw comparison data (CSV)](oss_benchmark_30.csv)
- [Formatted comparison workbook (XLSX)](oss_benchmark_30.xlsx)

The snapshot date and limitations are documented in each report. The original 50-project candidate list, exact discovery queries, and exclusion log were not retained, so the 30-project set must not be presented as independently reproducible. GitHub stars are treated as an adoption signal, not as a measure of software quality or proof that a particular communication tactic caused growth.
