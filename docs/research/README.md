# ExecLocus research

This directory contains reproducible research used to shape the product and release strategy.

- [30-project OSS benchmark](OSS_BENCHMARK_30.md)
- [Launch and communication playbook](LAUNCH_PLAYBOOK.md)
- [Raw comparison data (CSV)](oss_benchmark_30.csv)
- [Formatted comparison workbook (XLSX)](oss_benchmark_30.xlsx)

The snapshot date and limitations are documented in each report. GitHub stars are treated as an adoption signal, not as a measure of software quality or proof that a particular communication tactic caused growth.
