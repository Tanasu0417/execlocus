# Local GUI and language validation — 2026-07-30

## Scope

This record covers the pre-alpha local diagnostic GUI, English/Japanese human-readable output, the loopback request boundary, and Share-view redaction. It intentionally contains no raw diagnostic values, account names, machine names, home directories, or personal absolute paths.

## Implemented behavior

- `execlocus gui` serves the embedded interface only on `127.0.0.1`; port `0` selects an available local port.
- Selecting the diagnostic button runs the existing read-only probe pipeline and rule engine.
- Inspect and Compare receive local-only report data; Share receives an independently redacted report and redacted Markdown.
- Compare renders the four selection states, selected binding kind, candidate count, origin, PE/ELF/script format, reason, and independent verification command.
- Explain renders the first active finding with impact, read-only actions, reverification steps, and referenced evidence.
- `--lang en|ja` localizes terminal, Markdown, explanation, and real GUI copy. JSON field names, rule IDs, commands, and observed paths remain stable.

## Boundary controls

- The server accepts only a loopback Host and binds no LAN interface.
- Browser diagnostic requests require a custom header and a same-loopback Origin when Origin is present.
- No CORS response is emitted, responses disable caching, and static pages receive a restrictive Content Security Policy.
- No telemetry, hosted backend, paid API, auto-fix, or configuration write is used.
- Local diagnostic views can contain identity and path data by design; only the separately redacted Share view is intended for review as a public attachment.

## Remaining human gate

The repository owner must run the published Windows and/or WSL wrapper and answer whether the result:

1. revealed a previously unnoticed Windows/WSL boundary;
2. shortened the time needed to reach a decision; and
3. would be reused for the same uncertainty.

This value judgment cannot be completed by automated tests and is the next user-operated gate.
