# ExecLocus interactive concept demo

This is a local-only, synthetic interaction prototype. It does not execute probes and is not the v0.1 CLI surface.

Open `index.html` directly, or serve the parent `docs/demo` directory from a local static web server and open `/prototype/index.html`. Use the left rail or number keys `1`–`4` to move between Inspect, Compare, Explain, and Share. Press `R` to replay the diagnostic transition.

Stable capture URLs:

- `index.html?view=inspect`
- `index.html?view=compare`
- `index.html?view=explain&profile=balanced`
- `index.html?view=share&profile=share-first`

The 60-second caption master is `mv.html`. Add `?autoplay=1&capture=1` for a clean autoplay surface. It is a concept animatic, not a final MP4 and not evidence of a released binary.

All paths and identities in the prototype are synthetic. The otter is an original project-native SVG and does not trace the earlier third-party reference image.
