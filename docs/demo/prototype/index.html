この選択の意味

EXECUTION CLARITY FOR WSL2

「どれが実行される？」を、実行前に見抜く。

同じプロジェクトでも、WindowsとWSLではGit・Node・Codex・Claude Codeの選択が変わります。ExecLocusは、その違いと影響、直し方を1画面にまとめます。

01実行場所が分かる

Windows、WSL、ディストリビューション、シェル、プロジェクト境界を判定します。

02選ばれるツールが分かる

Git・Node・npm・Codex・Claude Codeの候補と、実際の優先順位を確認します。

03次の行動が分かる

不一致の影響、修正候補、確認コマンド、再診断手順を表示します。

防げる問題

動くけれど、思っていた環境と違う。

  • WSLで作業しているのにWindows版Nodeが選ばれる
  • 依存関係やキャッシュが意図しない側へ作られる
  • 人によって再現結果が違い、原因調査に時間がかかる
安全な診断読み取り専用・外部送信なし・有料APIなし。診断結果はこのPC内だけに表示します。
