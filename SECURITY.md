# Security Policy

## Supported versions

ExecLocus is currently pre-alpha and has no supported release line. Security fixes
will be applied to the default branch until the first versioned release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository:

https://github.com/Tanasu0417/execlocus/security/advisories/new

Do not open a public issue for a suspected vulnerability. Do not include real
credentials, tokens, private keys, personal absolute paths, or other identifying
data in a report. A minimal synthetic reproduction is preferred.

Reports are reviewed on a best-effort basis. Confirmed issues will be assessed for
impact, fixed privately where practical, and disclosed after a remediation is
available.

## Scope priorities

Reports are especially useful when they involve:

- disclosure of secrets or personal system information;
- unsafe filesystem or process behavior;
- incorrect redaction in shareable reports;
- untrusted input affecting command execution;
- dependency or release artifact integrity.
