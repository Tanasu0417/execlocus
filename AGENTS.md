# Repository instructions

## Cost policy

- Treat the project's default incremental budget as 0 JPY.
- Do not invoke metered APIs, hosted AI models, paid cloud resources, paid
  runners, or paid external services without the repository owner's explicit
  approval for that operation.
- Treat trials, promotional credits, and paid-subscription quota as cost-risk,
  not as free usage.
- Do not add or use API keys, cloud credentials, billing accounts, usage
  credits, or payment methods for project work without explicit approval.
- Installing a client does not authorize calls to its paid backend.
- When cost or authentication is unclear, stop before use and report the
  service, authentication route, possible charge, data exposure, and a no-cost
  alternative.
- Follow [COST_POLICY.md](COST_POLICY.md) for the complete policy.

## Privacy

- Never commit credentials, billing information, personal identities, machine
  names, or personal absolute paths.
- Use synthetic values in public fixtures and documentation.
